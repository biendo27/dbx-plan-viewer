# Changelog

## 0.1.1 — 2026-11-17

First public release of SQL Plan Viewer for DBX 0.6.71 or later.

- Offline SQL Server ShowPlan XML via result-grid View Plan, paste and local files.
- Multiple plan cells and procedure statements, original XML, source-derived
  properties, estimated and available runtime rows.
- Studio layout, operator icons, right-to-left graph, pan/zoom/Fit, keyboard
  selection, light/dark and narrow layouts.
- Estimated exclusive operator cost percentages relative to the current
  statement, with unavailable values for missing or inconsistent source data.
- No requested host permissions, SQL execution, AI, network runtime or sidecar.
- GitHub Actions pinned to checkout 7.0.1, setup-node 7.1.0 and upload-artifact 7.0.2.

Local version 0.1.0 was used for initial desktop validation and was not publicly
released. Packages are unsigned until separately reviewed and signed by DBX Store.
